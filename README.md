# Cryptanalysis & Cyber Defence

A collection of practical implementations, experiments, and security concepts developed as part of the **Cryptanalysis & Cyber Defence** course.

## About the Repository

This repository contains implementations and experiments related to **cryptography, cryptanalysis, network security, and cyber defence**. It covers classical and modern cryptographic techniques along with practical approaches to identifying, analyzing, and mitigating security threats.

The projects and programs in this repository are intended for **academic learning, experimentation, and cybersecurity education**.

## Objectives

- Understand fundamental cryptographic concepts and algorithms.
- Implement classical and modern encryption techniques.
- Study cryptanalysis and methods used to evaluate cryptographic security.
- Explore authentication, hashing, and digital signatures.
- Understand common cybersecurity threats and attack vectors.
- Develop practical cyber-defence and security analysis skills.
- Apply theoretical security concepts through hands-on implementations.
